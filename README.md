# Locksmith Nomad LLC — Website

English-language static website for GitHub Pages.

## Launch
1. Extract this ZIP completely.
2. Open `index.html` in Chrome to preview. Keep the `assets` folder alongside the HTML files.
3. Create a GitHub repository, upload **the contents** of this folder to its root.
4. GitHub repository Settings → Pages → Deploy from a branch → main / (root).
